# 📰 NotiPress Internacional - App Oficial para Android (v1.0.0)

Aplicación oficial del portal de noticias **NotiPress Internacional** (https://notipressinternacional.com.ar/).

### ✨ Características principales:
* 🔔 **Notificaciones Push:** Alertas de noticias urgentes y de último momento en tiempo real.
* ⚡ **Navegación Ultrarrápida:** Modo optimizado con bajo consumo de datos y batería.
* 🔄 **Pull-to-Refresh:** Desliza hacia abajo para actualizar la portada al instante.
* 📤 **Compartir:** Envía noticias directamente a WhatsApp, Telegram y redes sociales.
* 🛡️ **Segura y Ligera:** 11.8 MB, 100% libre de virus y compatible con Android 12, 13, 14 y 15.

Descarga el archivo **`NotiPressInternacional-release.apk`** ubicado debajo en la sección de *Assets*.
