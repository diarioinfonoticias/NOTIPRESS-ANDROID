### ⚙️ Requisitos y Optimización de Batería

Debido a que **NotiPress** utiliza componentes avanzados de fondo (`WorkManager` y `NewsCheckWorker`) para verificar nuevas noticias en tiempo real, algunos sistemas operativos Android pueden pausar la aplicación para ahorrar batería.

Para garantizar que recibas todas las alertas al instante, sigue estos pasos tras instalarla:
1. Mantén presionado el icono de **NotiPress** en tu pantalla de inicio y selecciona **Información de la aplicación** (o el icono de la "i").
2. Ve al apartado de **Batería** o **Uso de batería**.
3. Cambia la configuración de *Optimizado* a **Sin restricciones**.
