# 📰 NotiPress Internacional — App Oficial para Android

Aplicación oficial del portal de noticias **[NotiPress Internacional](https://notipressinternacional.com.ar/)**

[![Descargar APK](https://img.shields.io/badge/⬇_Descargar-APK_v1.1.0-A80000?style=for-the-badge&logo=android)](https://github.com/diarioinfonoticias/NOTIPRESS-ANDROID/releases/latest)

### ✨ Características principales
* 🔔 **Notificaciones Push:** cada noticia publicada llega sola a tu celular, en tiempo real.
* 📲 **Directo a la noticia:** tocás la notificación y se abre la nota completa en la app.
* ⚡ **Navegación ultrarrápida:** modo optimizado con bajo consumo de datos y batería.
* 🔄 **Pull-to-Refresh:** deslizá hacia abajo para actualizar la portada al instante.
* 🛡️ **Segura y liviana:** menos de 3 MB, compatible con Android 12, 13, 14 y 15.

### 📥 Descarga
Descargá el APK desde la sección de **[Releases](https://github.com/diarioinfonoticias/NOTIPRESS-ANDROID/releases/latest)** — es el archivo `NotiPress-Internacional-v1.1-release.apk`.

1. Descargá el archivo en tu celular
2. Abrilo y permití la instalación si el sistema lo pide
3. Aceptá las notificaciones… ¡y recibí cada noticia al instante! 🔔
